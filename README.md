# Projeto-Keylogger-e-ransoware


📌 Título

Simulação de Malware em Python (Educacional)

📖 Descrição

Este projeto demonstra, de forma controlada e educativa, o funcionamento de dois tipos comuns de malware:

Ransomware
Keylogger
🎯 Objetivo
Entender como ataques funcionam
Aprender como se defender
Criar consciência em segurança digital
🔐 Ransomware (Simulação)
Explicação do ataque
Demonstração com arquivos de teste
Conceito de criptografia
⌨️ Keylogger (Simulação)
Demonstração de captura controlada
Explicação de funcionamento real
🛡️ Defesa
Boas práticas de segurança
Ferramentas recomendadas
